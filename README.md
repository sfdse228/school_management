# 🏫 Система управления онлайн-школой

Полноценное консольное приложение для управления студентами, преподавателями и курсами с аналитикой успеваемости.

## 📋 Функции

### Управление пользователями
- Добавление студентов (имя, email)
- Добавление преподавателей (имя, специализация)

### Управление курсами
- Создание курсов (название, тема)
- Назначение преподавателя на курс
- Зачисление студентов на курс
- Выставление оценок (0-100)
- Завершение курса с фиксацией результатов

### Аналитика
- Отчёт по студенту (активные/завершённые курсы, оценки)
- Топ студентов по успеваемости
- Статистика по курсу (средняя, max, min оценки)

### Хранилище
- Автоматическое сохранение в JSON
- Загрузка данных при запуске
- Восстановление всех связей
